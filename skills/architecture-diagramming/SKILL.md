# 建筑与城市分析图：从证据到设计动作

目标是让图帮助用户做一个空间决定。保留用户已确定的风格、图种、范围与交付要求；在其约束内选择表达。不要为了套流程增加图纸数量。仅策划时给可执行建议；只有用户要求实际制图/改图时才调用 Illustrator。

## 工作方式

先从现有材料确认当前要判断的设计问题，给出可审阅的简短设计决策卡：**问题 → 证据与缺口 → 要表达的关系 → 抽象与编码 → 图中结论 → 设计动作与验证**。这是向用户说明依据和选择的工作记录，无需输出隐含思维过程。

关键规则：

- 看实际图像或图纸再判断空间。文件名、OCR 和对象清单只能辅助；无法看图时限定结论范围。
- 分清 `observed`（直接可见）、`supplied`（资料提供）、`inferred`（推断）、`proposed`（提案）；分别说明几何与语义的依据。用户提供的信息有来源，但不等于经过独立验证。
- 保留决定结论的拓扑、尺度、方向、时段和对照条件。删去无关细节时，不删掉门、障碍、服务空间或反例来让结论显得成立。
- 路径、关系连线、视线和力/风/水流属于不同语义；明确图例。没有数量数据时，线宽只表示阅读优先级，不能暗示流量。
- 示意、模拟和实测分开。没有数据不画伪热图，不补猜测的北向、比例尺、人数和性能百分比。
- 缺资料时先完成可成立的部分，再按“会不会推翻决定”排列补证优先级。不要让可选风格信息阻塞工作，也不要把关键未知变成默认事实。
- 图必须回到具体设计动作及其代价。图面漂亮不能替代入口可达、功能可运营或性能得到改善的证据。
- 城市任务先区分设计、研究、影响与参照边界；不要把半径圆当路网步行圈，也不要把路段交叉默认成可以通行。设施须核查真实入口、开放时段和服务资格；统计须说明分母、时间与空间单元。

## 完成标准

策划交付包括选择的分析切入点、具体要画的元素与依据、可支持的结论、补资料优先级和下一设计动作；无需强制固定模板或固定图数。实际制图还要重新查看成图，检查底图配准、路径穿越、证据状态、图例、文字和版本，按用户要求保存。明确哪些已生成、哪些仅建议、哪些仍待验证。
