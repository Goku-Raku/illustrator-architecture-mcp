# 城市小区域与 site analysis：从城市关系落到可实施的干预

适用：街区、社区、站点周边、河岸、旧城片区、校园外缘及一组城市街道的分析与设计。建筑可以是对象之一，研究单位还包括街段、路口、地块、设施网络、使用群体和运营时段。不要把建筑平面放大后套用室内流线图。

按需继续读：[40 个城市分析维度](urban-analysis-atlas.md)｜[河流与快速路片区教学案](urban-worked-example.md)｜[通用证据方法](method.md)｜[视觉语法](visual-language.md)。本文件提供方法与条件；真实项目的法规、通行权限、最新运营和数据许可仍以当地已核实资料为准。

## 1. 先辨认要改的关系，而不是先定一张“场地综合分析图”

将“交通、景观、文化、功能”改写为能影响方案的句子。例如：市场距离车站不远，为什么晚间仍难到达？绿地总量不少，为什么放学后没有可停留的位置？街墙连续，为什么步行体验却断开？增加一条穿行线，谁获得便利、谁失去安静或经营位置？

用 **城市系统 → 小区域机制 → 具体干预 → 返回城市系统复查** 往返工作：区域交通识别主要来向，片区网络定位断点，街段剖面检查修补是否容得下，最后再看是否把车流、积水或搬迁代价转移到周边。跨尺度不是把同一张图缩放三次；每层保留的变量和提出的问题应不同。

## 2. 一开始就分清四种范围

| 范围 | 回答什么 | 怎么确定和表达 | 最容易遗漏的部分 |
|---|---|---|---|
| 设计边界 | 此项目实际能改变哪里、由谁实施？ | 委托/用地/管理范围的明确线；外部建议另标 | 有设计意愿不等于有土地或道路管理权 |
| 研究边界 | 为了判断设计，需要掌握哪些关系？ | 随问题扩展的范围；可含界外桥、入口、上游汇水、竞争设施 | 裁掉界外另一座桥，会人为制造唯一通路 |
| 影响范围 | 干预的收益与代价可能传到哪里？ | 有依据的受影响对象/路径/下游，不一定闭合为一个面 | 拥堵转移、租金变化、施工绕行、雨水下泄 |
| 参照范围 | 与谁、哪一时点、什么基准比较才有意义？ | 同类街段/社区、同一片区改造前、明确基准方案 | 拿不同人口结构、面积口径或气候条件的地区直接排名 |

四者可以重叠，却不应默认相同。图上分别命名；非必须同时出现时，以定位图加简短范围说明代替四套边界硬叠。一圈 300/500 米只能被称为指定中心的直线距离范围；除非有相应网络和条件，不能改叫步行服务区、五分钟生活圈或真实影响范围。

下表只帮助选择工作粒度，不规定固定半径或固定比例尺。

| 层次 | 用来判断 | 主要抽象 | 下钻/返回的信号 |
|---|---|---|---|
| 城市/流域/交通走廊背景 | 片区在更大系统中承担什么作用、受何种外部条件影响？ | 城市节点、通道、上游/下游、就业/居住联系 | 某条重要联系在设计边界外断开，需扩大研究范围 |
| 社区/站区/相邻街区 | 哪些人可到哪些资源；哪些空间组合支撑日常生活？ | 路网、设施供需、街区结构、分群体与时段状态 | 同一条网络连接对不同人不成立，需到入口/高差层核查 |
| 街段/路口/地块组 | 断点和冲突具体由什么造成？ | 界面分段、过街链、底层用途、树荫与等候空间 | 路幅内方案放不下，需返回网络层寻找替代或调分工 |
| 门口/角落/街道剖面 | 进入、停留、排队、维护能否同时成立？ | 门槛、尺寸、连续路径、活动占域、视线/高差 | 局部优化迫使另一人群绕行或排水改道，返回片区复查 |

## 3. 资料按“会改变决定”收集

先选要回答的少数问题，再选 [城市分析图谱](urban-analysis-atlas.md) 中相关项。不是先下载所有图层再找故事。底图、运营与观察不是同一类证据；一个数据集也不替另一个数据集背书。

### 最小资料台账

| 项目 | 应保留的信息 | 实际用处 |
|---|---|---|
| 身份与来源 | dataset/feature ID、发布者/链接、文件版本、许可与署名要求 | 更新时仍能定位原对象；保留必要底图归属 |
| 时空范围 | 采集日期、统计期、工作日/周末、时段、调查范围与缺测区 | 不把旧店铺数据和新路网拼成一个假“现状” |
| 位置与精度 | 坐标参考系、坐标单位、几何精度、地理配准依据、是否手绘 | 经纬度不能直接作为米；未配准截图不能量距离/面积 |
| 分析单位 | 人/人次/出行/店铺/入口/地块/建筑/统计区，重复记录规则 | 门店数不等于服务人数；车站中心点不等于入口 |
| 数值口径 | 分子、分母、单位、容量定义、缺值代码、聚合/插值方法 | 未知不变成零；各图能公平比较 |
| 证据状态 | observed / supplied / inferred / proposed；关键假设与验证状态 | 几何存在和允许通行分别记录 |

不强制每次建立数据库。小项目可用一张表；复杂项目应留原始数据和转换后的版本，按稳定 ID 关联图上对象。不同精度数据共用一张图时，表达精度由实际证据决定，不能让清晰矢量线伪装成精确测绘。

### 资料来源的职责

- **基础空间**：当地开放地理资料、现行地籍/规划资料、可靠测绘、用户底图。在线地图和街景可发现线索；标注拍摄/更新日期，关键门和跨越现场核查。
- **人口与活动**：当地统计机关的边界和同年份数据、设施服务对象资料、分时观察。行政区人口不能凭面积切成“每栋楼的人口”；移动位置样本不能自动代表所有居民。
- **网络与服务**：道路/人行设施、真实站点入口、班次/开闭时间、坡道/电梯状态、过街方式。道路中心线通常缺少足以支持轮椅通行判断的信息。
- **环境**：相关尺度的地形、汇水/排口、气象、树冠和有时间戳的实测/模拟。风玫瑰提供气象背景，不直接提供每条街的风速。
- **运营与经验**：设施管理人资料、访谈、场地观察、使用者记录。保留采样对象、时间与方法；不以某群体没有被观察到就判定没有需求。

若只有底图：先能做形态、明显阻隔、可辨入口和待核查位置图；把最能推翻方案的几项未知排到前面。不要以随手画的热图或风箭头补足空缺。

### 只有底图时，首张图怎样起稿

先做一张“连接与未知条件图”：淡化底图；标设计范围与需要延伸的研究范围；描出有依据的河流/铁路/快速路/围墙；点出可辨的入口和跨越；只连已经成立的路段，把相交但连接不明、关门时间不明的位置加问号。旁边写本图试图决定的一个入口、通路或功能位置问题，以及最可能推翻它的三项补证。没有度量就标拓扑示意；昼夜规则不同则复制同一底图对照。先用这张图决定下一步去查哪里，再按问题增加功能、活动或生态图。

## 4. 城市图先保留拓扑，再处理样式

### 路网不只是粗细不同的道路

建立“节点—路段—条件”关系时，至少检查本题涉及的路口、过街点、桥/隧道、入口、高差连接、单行/权限与时段。两条线在平面上相交，可能是立交；一条断开的绘图线，也可能只是数据切段。几何接近不等于连接。

同一处设施可有多个入口。起终点应落在适用入口及其可到达边，不自动吸附到最近的车道中心线。对步行、推车/轮椅、骑行、货运分别选择必要条件；不预设一个“普通人”网络对所有人适用。无障碍相关设计核查按项目所在地适用依据另做，分析图不构成合规证明。

服务区应说明行进方式、起点入口、距离或时间阈值、开放时段、障碍和计算方法；时间还涉及速度、过街等待、坡度/楼梯、换乘及设备可用条件。Esri 的服务区定义基于网络成本，障碍可以限制通行或改变成本；这说明几何半径和网络可达不是同一种结果。[服务区文档](https://pro.arcgis.com/en/pro-app/3.6/help/analysis/networks/service-area-analysis-layer.htm)、[障碍文档](https://pro.arcgis.com/en/pro-app/3.4/help/analysis/networks/barriers.htm)。没有计算时可交付“已核实连接图/障碍图”，不命名为等时圈。

### 用地、建筑、街道界面分层

地块是产权/管理和开发组织单位，建筑是三维使用载体，底层界面是与公共空间交互的边，街区是被网络围合的结构。它们不能用一个色块代替。

- 黑白底图（figure-ground，建筑实体与空隙）能看粒度、围合和连续性；白色部分仍可能是私院、停车场、围墙内空地。
- 地块用途说明整体类别；底层沿街分段和上层用途小图解释“外面看起来混合，日常是否真的能相遇”。
- 开口、透明度、停留条件、活动时段分别编码。玻璃沿街不自动表示可进入、对外营业或适合停留。
- 高度图和街道剖面相互校核；平面建筑密度不能代替容积量、遮阴或街谷感受。

## 5. 让资料成为图形，同时让图形保留限度

| 信息结构 | 优先表达 | 足够支持什么 | 需要防的偷换 |
|---|---|---|---|
| 实体/空隙/地块粒度 | 黑白底图＋地块细线；必要时类型剖面 | 形态结构与候选穿行位置 | 空白≠公共，细碎≠天然有活力 |
| 开放界面/盲墙/店面/入口 | 沿真实街边的分段条带＋门节点 | 界面与路径/活动的空间对应 | 线段颜色不证明真实客流或经营质量 |
| 网络/阻隔/过街条件 | 路段、连接节点、阻断符号、跨越局部剖面 | 条件下的连接和断点 | 道路相交≠可换向，桥下≠可通行 |
| 设施数量与容量 | 类别点＋容量表；入口/时段关联 | 已知设施分布与供给条件 | 多个点≠服务充足，容量≠剩余容量 |
| 人口/需求率 | 同口径分区图或按有依据位置的比例符号 | 指定统计单元的平均差异 | 色块面积≠人口；区平均不代表每个人 |
| 通行与停留观察 | 计数断面、方向箭头、定位停留点＋观察时间条 | 指定样本时段的活动结构 | 过街人数≠独立使用者数，快照≠全天流量 |
| 运营状态/时间差 | 同底图小倍图＋设施/通道开闭表 | 时段切换如何改变网络和机会 | 营业时长不自动代表任何时刻都有容量 |
| 连续环境量 | 带单位/图例的真实栅格、等值线或测点 | 指定来源和条件的空间变化 | 颜色晕染不是实测；插值区不是采样点 |
| 记忆/感知/口述 | 地图位置＋照片/引述短片段＋采样说明 | 被记录的经验与价值分歧 | 单个访谈不替代整个社区意见 |
| 权属/维护/阶段 | 管理范围、责任节点、阶段小图与条件表 | 谁能实施、谁承担日常工作 | 图上可连通不证明能协商或持续开放 |

比例符号若用圆面积表达人数或容量，按面积比例构造，并说明单位；不要把半径线性放大。定性主次可以使用线宽，但图例应写“阅读层级”，不能写“人流量”。可数点的热图只在具备真实记录、权重、统计时段、搜索半径/带宽、输出分辨率与分析方法时生成；核密度呈现受这些条件影响的估计，不是热环境，也不证明设施服务效果。[Esri 核密度方法](https://doc.esri.com/en/arcgis-pro/latest/tool-reference/spatial-analyst/how-kernel-density-works.html)。

配色不足以解决复杂性。常用画面结构是“一个可定位的主图＋同范围分主题小图＋决定成败的街段剖面/路口放大＋短条件表”。每个新增图都应帮助区分方案、补足证据或表达取舍；不要求把 40 个维度都画一遍。

## 6. 地图统计的五个具体陷阱

1. **分母不一致**：设施/平方公里、设施/千名居民、学位/适龄儿童、开放小时/周，回答不同问题。先定服务对象与容量口径，再制图；有点位但无容量/需求时只表达分布。
2. **范围改变结论**：同一数据改变汇总单元大小，或同样大小却换一种分区，结果可能变化，这就是可变空间单元问题（MAUP）。本项目的应对是保留原单位、比较一组合理替代边界、检查界外资源，不把某一种分区结果当自然边界。[Esri 对尺度效应与分区效应的说明](https://support.esri.com/en-us/gis-dictionary/modifiable-areal-unit-problem)。
3. **按面积均摊人口**：面内平均数不说明居民均匀分布；公园、水面和工业用地尤其不能承接随意人口分配。若做分配估计，保留辅助资料、模型和误差，不让生成点被误认成住户地址。统计边界的年份也要与数据对应。[美国人口普查局对边界版本与面积口径的说明](https://www.census.gov/data/what-is-data-census-gov/guidance-for-data-users/frequently-asked-questions/how-can-i-find-the-land-area-of-a-geography.html)。
4. **缺测变成低值**：没有营业资料、未观测时段、无法访问的小区，不应涂成无设施/低活动。给未知单独编码；调查覆盖图必要时独立展示。
5. **同处一地就说因果**：店铺与人流重合，可以提出有关联的假设；不能仅凭叠图断言新增店铺必然增加人流。比较同条件前后、合理参照、干预机制和反例；无法分离因素时说明是组合变化。

要比较两个区域，应先核对样本时间、调查时长、资料覆盖、统计单元、面积/人口分母与分类阈值。图例范围跨图保持一致；不为每个区域单独自动拉满色带再比较强弱。

## 7. 从冲突叠图走到行动优先次序

冲突图不应结束在红色爆炸符号。为关键冲突保留 **位置/时段 → 涉及群体 → 机制 → 可动变量 → 实施主体 → 收益/损失 → 最少验证**。先处理决定网络能否成立的断点，再讨论品质提升是否有用；但不得用“效率优先”自动排除弱势群体的到达条件。

| 行动层次 | 何时考虑 | 典型动作 | 要带走的代价 |
|---|---|---|---|
| 运营与管理试点 | 主要断点来自时间/权限，几何连接已有 | 协商延长通道开放、货运错时、共享设施排班 | 管理工时、责任、安静时段、既有使用者权益 |
| 街段与节点修补 | 一两个真实空间瓶颈使完整日常链失败 | 调整过街、补坡道/等候空间、移门、连续遮雨/座位 | 路权/停车/树根/管线占用，维护和排水影响 |
| 地块/街区重组 | 局部补丁不能解决长期阻隔或功能缺口 | 增加通道、重配首层、补公共服务、串联公共空间 | 土地协商、施工阶段、经营中断、替代安置 |
| 城市系统协调 | 来源或后果主要在项目边界外 | 公交组织、跨河连接、上游雨洪、区域设施协作 | 更大主体协调、成本与周期；不得假装本项目可直接执行 |

不机械加权求“总分最高”。先列不能牺牲的条件、对哪些人有收益、谁承担代价和哪些未知可能翻转选择。未知是待验证，不能打零分。可逆试点常能验证运营假设；永久工程则需要相应测绘、容量、专业分析和实施条件。临时改变也要保证被研究的完整到达与服务链可用。

成果应能用一句有条件的话推动下一步，例如：“若南口夜间仍开放且管理人同意，先测试市场通道延长开放；同时修补南侧过街的连续可达性。北桥新增连接留作后续比选，因为当前尚无尺寸和实施权属证据证明它优于修补现有通路。”

## 8. 与 Illustrator MCP 的分工

Skill 负责选问题、选证据、选抽象和判断图能说明什么。GIS/网络分析/环境模型负责相应数据处理或计算；Illustrator MCP 负责可编辑图形、图层、注释、图例、比较排版和回读验证。工具画得出多边形，不代表已算出服务范围；画得出箭头，不代表已完成流量或排水计算。

若使用地图几何导入/编译功能，先读取当前工具 schema 和 [MCP 执行边界](mcp-execution.md)，确认接受的坐标参考系、单位、几何类型、孔洞处理、裁切和对象限制。保留原地理数据与稳定 ID，逐层抽查定位/孔洞/入口对应。不能编造参数，也不能把经纬度直接冠以米单位。一般地理 GeoJSON 与工具约定的投影平面输入不是同一个坐标约定，须明确转换和来源。

## 9. 公开方法来源及本套方法的转译
