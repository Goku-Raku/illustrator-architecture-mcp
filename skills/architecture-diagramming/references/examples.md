# 两种现实情境演示

以下均为自设教学情境，用来展示可审阅的决策过程，不是已调查项目，不声称做过实际人流观察或 Illustrator 绘制。每例先给原始输入，再给可以成立的分析和不能补造的内容。这里的字母仅为对象索引，不代表已知房间用途。

## 情境一：只有一张底图，用户要“先做场地和流线分析”

### 原始输入

用户：“只有这张首层截图，先帮我分析场地和流线，看看设计该从哪下手。”

教学底图转录如下。`│─` 是可辨识的墙/边界，缺口是图中可见开口，`?` 表示图像模糊、无法确定。图上没有比例尺、北针、功能文字、标高或门的开放信息。图幅上方/右方仅指图面方向，不等于地理北/东。

```text
                 图面上方道路轮廓
    ┌───────────────    ───────────────┐
    │       A       │       B         │
    │               │                 │
    ├──────   ──────┤────── ? ────────┤
    │                                 │
    │          中部连续空白带          │   图面右方有空地轮廓
    │                                 │
    ├──────   ──────┤──────   ────────┤
    │       C       │       D         │
    │               │                 │
    └───────────────    ───────────────┘
                  图面下方开口
```

附带信息：截图的房间边界可辨；右上 B 与中部空白带之间的连接模糊；没有其他资料。不能因为画面上有缺口就确认是可用的室外主入口。

### 先交付什么

**当前可成立的问题**：“图中哪些空间可能由中部空白带连接，哪些连接需要确认？”这能帮助确定先核实哪里、是否值得以共享通道为设计起点。广义场地结论暂时只能定位邻近道路/空地关系，不能推断土地权属、主来向或气候。

简短证据台账：

| 输入 | 状态与可说内容 | 不可附加的结论 |
|---|---|---|
| A/C/D 与中部空白带之间的缺口 | `observed`：图上有可辨开口；实际图片任务需亲自查看像素 | 不是已证实开放门、合规通道或使用强度 |
| 中部空白带 | `observed`：有连续未填实空间；`inferred`：可能承担联系 | 不能直接命名“公共走廊”，除非用户确认 |
| B 处模糊连接 | 待验证，单独标注 | 不能自动补门或画穿过该位置的确定性流线 |
| 上方道路与右方空地轮廓 | `observed`：相对位置 | 不能称“北侧道路”或“可建设用地” |

**图形计划**：保留底图；以 A–D 编号标出可辨空间，描中部空间范围；给明确可见缺口加小节点，给 B 模糊处加“连接待确认”引注。若需要表达通行猜想，用明确标作“候选连通示意”的关系图，不用粗细暗示人数；不添加假北针、比例尺、风向和密度点。

空间底图承载定位；可附简化邻接关系帮助检查：A—中部、C—中部、D—中部为“可见开口关系”，B—中部为“待确认”。这张关系图只回答图面拓扑，尚不回答真实可达。

### 补资料的先后

1. **会改变结论**：确认图中缺口是否为门、哪些能开放，B 连接是否存在；确认房间用途和图纸版本。若要讨论真实可达，补相关高差/标高。
2. **决定方案方向**：主要使用者、外部来向、想共享的功能、开放时段。需要距离/面积时补一个可靠尺度；需要朝向分析时补北向。
3. **表达调整**：最终图幅、配色和交付格式。可以先用可改样式，不阻塞前两项。

### 设计动作与验证

**条件提案**：“如果中部空间确实是可通行的共享带，且 B 需要共享到达，可比较保留独立入口与新增 B—中部连接；前者管理独立但联系弱，后者联系直接但可能引入噪声/管理穿越。”先比较关系，不在未知承重墙上直接画成已可施工的新门。

用户随后确认门与用途，才把候选关系升级为实际路径。真实量化分析仍需相应数据。若用户此时只要建议，交付决策卡即可；若已要求制图，则绘制有依据的覆盖层并标注关键未知。

### 决策卡样例

> 问题：中部空间是否能作为共享到达带？依据：A/C/D 缺口可见，B 连接模糊；用途与开放条件未知。表达：空间编号、开口节点、待确认引注及候选邻接。当前结论：图面具备部分连通条件，实际通行尚未确认。下一步：优先确认 B 与门状态，再比较独立到达和共享到达的管理代价。

## 情境二：跨时段共享图书馆，社区活动持续到闭馆后

### 原始输入

用户：“希望图书馆闭馆后社区活动还能继续，帮我看从什么方面分析，并给出分析图手法和可试的改法。”

教学输入为下列表格，均视为用户提供的方案/运营计划，非实测结果。没有尺寸、朝向和完整平剖，不可量出距离或宣布合规。

**空间与门的邻接表 v1**：只有列出的门被确认存在；未列出不能据此断言绝无其他门，应作为当前资料边界。

| 对象 | 已提供的实际连接 | 说明 |
|---|---|---|
| 街道 S | E1 → 门厅 L | 唯一已知室外入口 |
| 门厅 L | d1 → 阅览区 R；d4 → 楼梯 T | L 本身无厕所 |
| 阅览区 R | d2 → 社区活动室 A；d3 → 厕所 W | A、W 的唯一已知室内到达均经 R |
| 楼梯 T | → 二层安静阅览 Q | 标高/设备资料未提供 |
| 社区活动室 A | d2 → R | 需可独立晚间运营 |
| 厕所 W | d3 → R | 计划供 A 与 R 共享 |

**运营计划 v1**：

| 对象 | 开放时段 | 给定门禁规则 |
|---|---|---|
| L 门厅 | 08:00–22:00 | E1 随 L 开放 |
| R 阅览区 | 09:00–20:00 | 20:00 后 d1 关闭，R 不允许公众进入 |
| Q 二层安静阅览 | 09:00–20:00 | 20:00 后楼梯公众入口关闭 |
| A 社区活动室 | 14:00–22:00 | 20:00 后仍允许预约活动 |
| W 厕所 | 09:00–22:00 | 计划可用，但未提供独立路径 |

没有提供人数、噪声值、活动观察或家具转换时间。不要给“21:00 人流量”画散点热图。

### 从哪个方面着手

选 23 分时独立运行、14 支持空间依赖、06 到达路径三个维度，因为它们会直接改变门禁与空间分配。若后续活动要求说明有声学冲突，再补 16；此时无需先把所有环境图都做一遍。

把运营表转为状态检查：

| 检查情境 | 当前资料下的到达关系 | 图能支持的结论 |
|---|---|---|
| 18:00，R 与 A 同时开放 | S→L→R→A；A→R→W | 资料中的通路可连续；仍需平面几何/尺寸核查 |
| 21:00，仅 A 等晚间空间开放 | d1 已闭且 R 禁入；A 与 W 仍依赖 R | 运营计划与唯一已知路径相冲突，不能凭“W 开到 22:00”认定可使用 |
| 20:00 切换时刻 | 活动可能仍在 A，但公众通路状态改变 | 要检查闭馆前后人员如何离开、进入和使用支持空间；实际安排待补 |

“A 不可达”须限定为当前提供的连接网络，不断言建筑实际没有其他路径。这个限定比一个任意低置信度数字更清楚。

### 怎么画

- **运营矩阵**：横轴时段，纵轴空间；区域开放状态和门的关闭事件分别表达，突出 20:00 这个转换点。
- **同底图状态比较**：资料补齐后绘制 18:00 与 21:00；固定裁切、对象颜色和尺度，关闭区用统一状态编码。用门槛节点标 d1，用实际路径指出晚间断点。
- **支持依赖图**：L/A/W/R 的关系与真实通行区分开；让“厕所开放”和“厕所可到达”成为两个可检查条件。
- **提案对照**：用相同现状底图并列门禁/路径变更，明确拟新增范围，保留基准方案及被牺牲面积/管理范围。

这些图按交付和复杂度可合并，不是强制四张。图面颜色主要编码空间身份，开闭状态另用边界/纹理及文字；现状与提案必须可辨。不存在可核查平面时，先出矩阵与拓扑关系示意，不把拓扑连线硬映射成 Illustrator 中的真实走廊。

### 两个可试方案及取舍

| 提案 | 具体空间操作 | 收益与代价 | 还需验证 |
|---|---|---|---|
| A：把共享通路纳入晚间开放边界 | 从 R 边缘划出通往 A/W 的独立可控通道，调整 d1 与其他门禁；不让路线穿越关闭书架区 | 可能保留 W 和 A 原位；需占用阅览空间，增加边界/管理复杂度 | 平面是否有足够空间、门与家具是否冲突、夜间管理范围；尺寸与现场条件 |
| B：形成独立社区入口与支持节点 | 在可行的外部界面给 A 独立到达，并为 A 提供无需穿 R 的 W 连接或独立厕所 | 运营独立性较强；可能增加改造量、设施面积和维护 | 外部界面是否可开口、厕所位置/管线、管理与其他必要通行；不预设能施工 |

两案不先打总分。若管理资源有限且有可用外部界面，B 值得优先测试；若改造范围严格且 R 边缘空间足够，A 值得先画平面试排。两个条件都未知时，优先补它们，而不是在没有依据时宣布某案最佳。

### 缺资料优先级与完成判断

首先获取首层平面、所有门/可用室外界面和门禁范围，查清 A/W 有无未列路径；这些可能直接消除或改变矛盾。其次补活动类型、管理方式、家具与人数需求，决定缓冲、容量与支持设施策略。距离/面积/无障碍结论再补可靠尺寸/标高和适用条件。最后统一图幅与样式。

闭环不是“画完时间轴”，而是“给每个选定状态提供不穿关闭区的到达—使用—离开关系，并明确设施依赖与方案代价”。达到当前阶段的空间与运营检查后，再按需要推进性能或专业核查。
