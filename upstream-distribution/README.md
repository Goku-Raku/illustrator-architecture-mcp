# Archived upstream distribution metadata

These `.txt` snapshots preserve the original project's MCPB manifest, MCP
Registry definition, Glama identity, Claude marketplace/plugin files and plugin
documentation. They are historical material, not installers for this fork.

The alpha intentionally has no MCPB package, marketplace registration, MCP
Registry entry or public npm publication. Installing the archived launchers would
run the upstream package instead of this fork, so their active entry points were
removed. The current supported routes are a source checkout or a versioned npm
tarball attached to a GitHub prerelease. See the root README and UPSTREAM.md.

No upstream ownership, maintainer identity or registry namespace is claimed by
this fork. Release automation uses the repository in which it is actually run.
