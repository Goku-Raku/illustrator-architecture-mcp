# 第三轮：城市小区域与 site analysis

版本 `1.10.3-architecture.3`。此前 36 项中有 5 项场地/城市关系入口，但不足以覆盖完整街区、社区或片区问题。本轮将城市分析扩成独立方法分支，仍共用一个 `architecture-diagramming` skill。

## 方法上的补足

| 过去容易忽略 | 本轮补充 | 对设计的实际作用 |
|---|---|---|
| 把红线或半径直接当研究范围 | 设计、研究、影响、参照四种边界；跨尺度往返 | 不裁掉界外桥、上游、替代设施和外溢成本 |
| 道路只是几条粗细线 | 真实入口、桥隧、立交、通行资格、时段与完整到达链 | 区分断路、关闭、服务不可用和舒适度问题 |
| 单色块“混合用地” | 地块、建筑、首层界面、上层使用、空置与经营状态分别看 | 让更新动作落到可改变的界面、用途与运营 |
| 设施点多便算充足 | 容量、分母、人群、时段和服务资格 | 比较新增、共享、扩容和改善到达的不同作用 |
| 大箭头/热图替代证据 | 流量、停留快照、环境实测/模拟、推断分码 | 不把好看的表达误写成定量结论 |
| 绿量等于生态性能 | 蓝绿连通、汇水、渗透限制、热暴露、遮阴与时点 | 能提出需要验证的空间动作，同时保留取舍 |
| 概念图画完就结束 | 权属、维护、经营、阶段、可负担性与受益/受损群体 | 将空间建议转成能讨论实施责任的方案 |

完整正文：[城市工作流](../skills/architecture-diagramming/references/urban-site-analysis.md)、[40 个维度](../skills/architecture-diagramming/references/urban-analysis-atlas.md)、[完整教学案](../skills/architecture-diagramming/references/urban-worked-example.md)。每项维度包括问题、输入、抽象、画面手法、误读风险与设计动作。它们是选择菜单，不是 40 张必做图。

## 工具上的补足

| 能力 | v2 | v3 | 边界 |
|---|---|---|---|
| 城市地图配准 | 预览像素点 → 画板点 | 新增 `arch_prepare_site_map`，统一转换明确的平面/投影矢量数据 | 不下载地图、不重投影、不自动配准栅格 |
| 复用点/线/面 | 每类手工准备坐标 | Point/LineString/Polygon 与 Multi 形式一起变换，保留源 ID 对照 | 不自动按属性分类，不把点计算成热图 |
| 中庭、地块内空隙 | 区域不能带洞 | `compound_zone` 原生复合路径与 even-odd 真孔洞 | 不布尔求交；洞不能接触/嵌套；斜线仍不支持洞 |
| 系列图一致性 | 需手动控制每批变换 | 共享 extent、等比居中、明确 Y 轴、名义纸面比例 | 不修正投影误差；无法识别所有错误 CRS 声明 |
| 方法读取 | 六个 guidance 主题 | 新增 urban_site / urban_atlas / urban_example | 读取 canonical skill 文档，不伪装为完成分析 |

路径、地块和背景尽量用可编辑几何；复杂原始数据可在外部保留完整版本，在共同 extent 下分批。工具对超限输入报错，不截断。复合路径成员继续受样式工具保护，避免局部修改共享外观时波及其他环。

## 为什么继续用一个 skill

建筑与城市共享证据分类、视觉编码、比较和 Illustrator 执行规则。复制成两个广泛触发的 skill 会增加重复加载和不同步风险。因此主文件提供尺度路由，城市正文按需读取；MCP guidance 也读取同一份文件。用户可以只咨询分析方法，不必先开 Illustrator。

路网求解、真实缓冲/等时圈、空间统计、环境模拟和自动标签避让仍未实现。这些应从实际项目需求和输入质量出发，接相应工具；本次不把图形绘制包装成 GIS 运算。
