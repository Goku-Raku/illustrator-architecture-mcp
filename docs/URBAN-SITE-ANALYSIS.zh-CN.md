# 城市小区域 site analysis 扩展入口

上一版并非只讨论建筑本体：36 项中已有街区穿行、周边资源、界面、地形与视线。但城市部分主要是建筑周边的入口和空间关系，对街区形态、设施供需、公共生活、管理与更新代价展开不足。

本轮补为一套独立的城市小区域工作方法：从城市系统进入社区、站区、街区和街段，再回到城市系统检验影响。它与原来的建筑分析方法配合使用，不要求每个项目都制作完整套图。

## 这次实质补了什么

- **研究范围**：分清能设计的边界、必须研究的关系、可能影响的范围和用于比较的参照；不固定套一个 300/500 米圆。
- **城市形态**：实体与空隙、地块粒度、街区通透、建筑类型/高度、街墙与底层界面、上层用途和空置。
- **出行网络**：路口、两岸跨越、站点与站口、台阶/坡道、门禁、真实末段路径、方式转换、路边占用和日常物流。
- **设施与生活**：需求分母、服务容量、资格/费用、时段、活动链、通行与停留、微空间、休息遮蔽及不同人群的机会差异。
- **环境与历史**：地形/汇水/排口、渗透限制、绿蓝网络、热/阴影/风与污染资料、感官经验、历史层次和社区记忆。
- **实施与取舍**：产权和管理、维护、施工阶段、既有经营与住房的替代代价；把发现落实为空间动作或运营动作。

每个维度都写成 **问题 → 信息与抽象 → 元素与手法 → 最少资料 → 误读风险 → 设计动作、代价与验证**。重点是让分析改变入口、路口、街边、功能、时段或实施顺序，而不是让底图更热闹。

## 一个具体的区别

“市场距离站点 500 米”只能开始提出问题。完整分析要看：站点的哪个入口，隔河在哪座桥过，快速路怎么穿，入口和院内小路何时关闭，是否有台阶，目标时段市场是否仍提供服务，能否在活动结束后回到仍开放的入口。

因此同一任务可能需要 **连接图＋分时小图＋门/设施状态表＋关键节点剖面**。如果资料只有道路和建筑轮廓，就先交付可靠的结构与待核查节点；不生成虚假人流热图、等时圈、服务覆盖率或工程效果。

教学案提供完整的 16 条边和运营状态，明确是抽象给定情景；没有伪造现场观测。它对比“延长开门”“改变无台阶跨越”“补晚间服务”三类动作，展示为什么画通一条线仍可能没有解决日常活动链。

## Skill 与 MCP 如何配套

继续扩展现有 `architecture-diagramming` skill，以条件读取城市参考文件，避免另建一个内容重叠的 skill。Skill 负责判断分析问题、证据和表达；MCP 负责可编辑的地图元素、图层、注释、排版与回读。GIS/网络和环境计算仍应由相应资料与方法完成，不能由画面样式代替。

本页是方法入口，不宣称已为某个真实场地完成分析，也不把公开参考图当作项目数据。参考访问状态、官方方法来源及限制均写在相应研究和方法文件中。
