# 我可以从哪些方面开始分析？

从正在犹豫的设计决定开始选择，不需要把下列各项全部做成图。每个维度的详细正文都包括：**原信息 → 空间抽象 → 图形元素 → 最低输入 → 误读风险 → 可试设计操作与验证**。

完整图谱在 [36 个分析维度与设计动作](../skills/architecture-diagramming/references/analysis-atlas.md)，它也是配套 skill 和 MCP 只读方法工具使用的同一份正文。

**城市小区域任务请进入 [40 个城市分析维度](../skills/architecture-diagramming/references/urban-analysis-atlas.md)**：城市形态、路网、首层界面、设施供需、公共生活、环境、更新与实施。先读 [城市工作流](../skills/architecture-diagramming/references/urban-site-analysis.md) 选范围与问题，不局限于下表 01–05 的建筑周边分析。

| 你卡住的决定 | 优先查看的维度 | 常见图纸组合 |
|---|---|---|
| 建筑落在哪里、入口朝哪里 | 01 街区连通；02 周边资源；03 边界界面；04 地形；05 视线 | 场地底图＋连通/门槛；必要时补地形剖面或观察视点 |
| 人怎么来、怎么走、哪里冲突 | 06 分群体到达；07 交汇；08 垂直交通；09 连续可达；10 停留与通行；11 体验序列 | 实际路径＋节点放大；跨层关系用平剖对应 |
| 功能如何摆才可用 | 12 邻接；13 公私层级；14 支持依赖；15 功能量；16 混合冲突 | 邻接/支持矩阵＋实际平面，按问题补剖面 |
| 剖面和界面有什么设计价值 | 17 高差活动；18 厚界面；19 光；20 声；21 结构支撑 | 对应剖面＋活动/来源—路径—受体，量化须补数据 |
| 同一空间能否不同时间共享 | 22 分时占用；23 部分关闭；24 转换成本；25 季节天气 | 时间/状态矩阵＋同底图比较，让支持空间与门禁一起出现 |
| 哪个方案更好，为什么 | 26 体块后果；27 变量因果；28 收益代价 | 同尺度/同视点/同任务量对照＋差异或指标表 |
| 生态策略怎样落到空间 | 29 径流；30 栖地；31 遮蔽；32 通风 | 来源—路径—节点—受体，平剖联动；无模拟不画伪场图 |
| 既有建筑怎样保留与更新 | 33 保留依据；34 新旧接口；35 分期运营；36 材料再用 | 状态分码＋接口局部＋阶段图或构件去向，按问题选取 |

## 两条选择示范

**夜间共享图书馆**：从 23 的开闭状态开始，接 14 的厕所/储藏等支持依赖，再接 06/08 的到达与跨层路径。这样会暴露“空间名义开放，但到达必须经过已关闭区域”的问题。它会引导你改门禁、通路和支持设施，而不是只换功能色块。

**雨水公共空间**：先用 04 的真实地形和 29 的流向/蓄滞/溢流定位策略，再用 10 的停留通行和 31 的遮蔽检查空间是否好用。蓝色箭头只表达有依据的策略，水量和排放能力需要计算输入。

缺资料时先补最可能推翻决定的信息。例如共享使用先补门状态和支持设施，距离判断先补尺度，日照判断先补方向与时间；并非每图都应先画北针、树木和人物。完整示范与原始输入见 [两种现实情境](../skills/architecture-diagramming/references/examples.md)。
