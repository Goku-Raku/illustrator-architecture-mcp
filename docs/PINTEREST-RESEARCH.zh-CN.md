研究日期：2026-10-09（Asia/Taipei）。实际检查 **17 张不同 Pin 的公开图像**，覆盖时间、感官、活动、资源循环、视线、结构、体量、功能网络、权限、分类与适应性。

## 从画面中提炼的缺口

过去的色块、流线、边界、标签和斜线覆盖了基本绘制，却容易遗漏以下关系：

| 信息 | 可复用元素与手法 | 必要限定 |
|---|---|---|
| 谁在何处做什么 | 姿态、活动群、家具、停留点 | 观测、假设、提案分开 |
| 时间与共享 | 区间、事件、同底图小倍图 | 采样间隔、跨午夜、平日/周末 |
| 感官来源与强弱 | 节点、等级、范围面、纹理 | 类别、强弱、持续性分通道 |
| 观看与到达 | 眼点、目标、视线扇形；另画真实通路 | 眼高、遮挡、身体条件 |
| 资源流动 | 源—处理—储存—需求—排出网络 | 介质、方向、单位、系统边界 |
| 功能相容 | 泡泡、邻接/冲突矩阵 | 必须、偏好、禁止、未知分开 |
| 公私与权限 | 边界、控制点、开放状态 | 谁、何时、满足什么条件能过 |
| 构成与装配 | 分解组、对齐线、部件索引 | 共同视角、向量与接口 |
| 操作与比较 | 同底图序列、差异层 | 比较基准与不变量 |
| 类型与属性 | 分类树、缩略图、属性矩阵 | 分类口径、来源、未知 |

它们不是每张图的必备清单。先挑能改变当前设计决定的关系，再决定需要几张图及哪些元素。

## 提炼为可执行工作流程

1. **问题**：写清需要判断什么，例如“夜间只开放展厅时是否穿越办公区”。
2. **证据**：记录来自图纸、观察、用户资料、模拟还是假设，并列关键缺口。
3. **关系**：选关键对象、边界、场、事件与状态，限制本图要支持的主张。
4. **编码**：为颜色、线型、大小、纹理、箭头各写一句含义；引线、移动、关联、装配线分开。
5. **草图**：先对空间锚点、路径端点、剖切与时间状态，再定风格。
6. **比较**：共享范围、方向、比例、视角、图例；改变被研究变量。
7. **回应**：每项重要发现对应可画的设计动作、代价及验证方法。
8. **检查**：标题是否有证据，是否伪造强度，是否穿墙、错层、图例含混或标注碰撞。

方法放 skill，确定性几何、属性、身份及回读放 MCP。本轮实现范围与仍需组合/外部计算的内容见 [能力对照](UPGRADE-NOTES.zh-CN.md)。这里对时间区间、共享图例、自动避让等的研究建议不代表已新增专用接口。
